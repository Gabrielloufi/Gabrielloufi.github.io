Telco Churn Prediction Pipeline

Python · scikit-learn · PyTorch · MLflow · FastAPI · Airflow

A telecom operator losing subscribers wants to know who is about to leave. The model is the easy part; the project is the pipeline around it.

  • One ColumnTransformer holds every fitted transformation, so preprocessing travels with the model as a single artefact and the training split cannot leak into validation.
  • The decision threshold sits at 0.3, not 0.5. A false negative is a customer who cancels while nobody intervenes; a false positive costs one retention offer. The asymmetry belongs in the threshold, and the reasoning is written down in the repo.
  • A PyTorch MLP (64→32, early stopping) was trained and tracked beside the baselines. It tied with logistic regression, so logistic regression shipped — interpretable, cheap, and one less thing to explain to stakeholders.
  • pandera schemas act as a data contract for training and batch scoring alike; FastAPI serves /predict with Pydantic validation and latency logging; an Airflow DAG scores the full base daily as the primary deployment shape.

Purchase Propensity System

Python · DVC · MLflow · Docker · Streamlit

A predictive system for purchase propensity, built as an exercise in ML engineering rather than in modelling: the interesting constraint was that any teammate should be able to reproduce a result from a clean checkout.

  • DVC pipeline with explicit preprocess → train stages and versioned data.
  • Experiments tracked in MLflow, with trained models promoted through the Model Registry under semantic versions.
  • Random Forest classifier, unit-tested modules, ruff and a Makefile for the repetitive parts.
  • A Streamlit app for demos, containerised and deployed to Oracle Cloud with docker-compose.

2026 · Solo

tatametube

Python · Flask · SQLite · ffmpeg · three.js

A self-hosted library for jiu-jitsu instructional videos — the part of the collection no streaming service indexes properly. It runs on a Raspberry Pi at home and is reachable from anywhere over Tailscale.

  • Flask application with session auth, a media pipeline over ffmpeg, and a browsable catalogue backed by SQLite.
  • Transcription and translation tooling that reconciles technique names across Portuguese, English and Japanese — the same move has three names and no canonical spelling.
  • A glossary and equivalence map for terminology, plus a 3D skeleton viewer built on GrappleMap position data.

  • SQLite
  • ffmpeg
  • Whisper
  • three.js
  • Tailscale

couchPie

Raspberry Pi · Linux · Docker · Tailscale

A portable media centre that turns a Raspberry Pi into something more useful than a smart TV: Kodi as the interface, game streaming from a desktop over Moonlight, browser apps in kiosk mode, network shares, and remote access over Tailscale.

  • Staged build-out — local entertainment hub first, then remote access, then home-automation integration.
  • Documented as a reproducible setup rather than a pile of shell history, so someone else can rebuild it.
